# IJIEEB PAPER023634: Revision R1 evidence

**Branch:** revision/ijieeb-paper023634-r1  
**Manuscript:** SCOBY Watch: A Simulation-First IoT and Hybrid Decision Support Framework for Kombucha Fermentation Readiness Assessment

This directory contains **additional experimental evidence** produced in response to IJIEEB review. It does **not** contain the confidential reviewer PDF, editorial correspondence, a revised manuscript, or an accepted publication.

## Contents

- scripts/revision_experiments.py: executable experiment suite based on existing repository modules.
- results/repeated_group_splits_raw.csv: all five baselines evaluated across ten held-out batch splits (seeds 42–51).
- results/repeated_group_splits_summary.csv: average and standard deviation across splits.
- results/humidity_ablation_raw.csv and humidity_ablation_summary.csv: with/without humidity comparisons.
- results/hybrid_full_test_coverage.csv: full 980-sample test-set hybrid behavior per split.
- results/seed42_gradient_boosting_error_cases.csv: traceable prediction disagreements.
- results/experiment_metadata.json: environment and paired McNemar test metadata.
- docs/generator_parameter_inventory.csv: generator settings extracted from src/generate_dataset.py.
- docs/revision_findings.md: evidence interpretation and remaining limitations.
- figures/: generated 300 dpi plot output (created by running the script).

## Run

From repository root, in an environment with dependencies from requirements.txt:

    OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python revisions/PAPER023634-R1/scripts/revision_experiments.py

The script reads the canonical dataset at data/scoby_watch_simulated_dataset.csv and writes CSV outputs in results/ and a 300 dpi PNG in figures/. Do not duplicate the dataset in this folder.

The original study and this revision evaluate *synthetic labels generated by deterministic rules*. The scores **must not** be described as empirical fermentation-readiness accuracy. Split test sets overlap across seeds; no independent external validation was conducted. The source code and results can vary slightly by dependency version; compare against the metadata of the recorded run.
